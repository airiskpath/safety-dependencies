# The list — a dated snapshot

**As of 26 September 2026.** For each of the eight families of defenses, what is missing today
for a named harm to become possible, who holds the lever, and what would count as proof that it
fell. We call such a defense a **lock**: a defense that still holds.

**A snapshot, not an index.** Each entry states what held on a given date, with its source.
New snapshots are published monthly; earlier ones are never overwritten.

**One file per family:** capability, resource, identity, access, duration, tacit knowledge,
defensive barrier (shown on the site as *installed control*), not tested. When no published
source establishes a lock for a family, the file says so with a `not-tested` entry. That is a
result, not an omission: it says nobody has checked.

**Two fallbacks that do not mean the same thing.**
- `not-tested`: the world is silent. Nobody has checked, so it may already be possible.
- `unspecified`: the source is silent on that field. The fact is sourced; that field is not documented.

Neither is ever filled in by inference.

**`status`** is `admitted` when the entry passes the admission rules, or `not-tested` when it records that nobody has checked.

**What is excluded, always.** An entry that names a way through rather than what blocks is
neither published nor kept. The verdict is recorded in `bypass_verdict` for every entry.

**Every figure carries its caveat.** Where an entry contains a number, `required_caveat` states
the limit that travels with it.

**Self-interested sources** are admitted, flagged as such, and never the only support of a claim.
